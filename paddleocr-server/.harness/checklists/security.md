# Security And Operations Checklist

- 将上传的 PDF、图片、TIFF 和解析文本视为不可信数据。
- 不提交真实 `.env`、内部地址、账号、令牌或其他秘密。
- 不在日志或交付说明中泄露宿主机敏感路径及环境变量值。
- 不删除或清空宿主机 PaddleX 模型缓存。
- 修改缓存挂载前确认宿主机与容器路径以及运行用户。
- 修改 CUDA/NPU 设备可见性时，确认不会占用未授权设备。
- 不在缺少实机依据时移除 `privileged`、驱动挂载或设备配置。
- 修改对外端口或监听地址时，评估服务暴露范围。
- 修改镜像标签前确认来源、平台和依赖兼容性。
- 压测前确认目标、文件和并发范围，避免冲击生产服务。
- 不将完整解析结果或用户文档写入 `.harness/runs/`。
